# KAS mascot state sprites

Four-frame transparent PNG sprite sheets generated with the integrated ImageGen
tool on 09/09/2026. Each asset preserves the KAS parcel courier identity from
`../kas-parcel.png`, with one horizontal frame sequence:

| Asset | Frames left to right | Runtime state |
| --- | --- | --- |
| `kas-parcel-idle-sprite.png` | rest, inhale, blink, rest | `idle` |
| `kas-parcel-listening-sprite.png` | neutral, lean left, lean right, neutral | `listening` |
| `kas-parcel-thinking-sprite.png` | ponder, look up, blink, realization | `thinking`, `searching` |
| `kas-parcel-result-sprite.png` | smile, raise hands, wave, ready | `result` |

Generation prompt contract: original warm-tan cardboard parcel courier with
oversized orange delivery cap, orange neckerchief, navy boots and dark navy
linework; polished flat 2D UI illustration; full body centered at equal scale
in four cells; actual transparent alpha background; no floor, shadow, badge,
text, logo, watermark, props or additional characters. The state-specific pose
sequence above is the only intentional variation.
